# Binary Tree Traversals and Search

## Aim

To construct a binary tree, perform tree traversals, and search for a given key in the constructed binary tree.

## Requirements

- Java JDK 8 or later
- Command Prompt, PowerShell, VS Code, IntelliJ IDEA, or any Java-compatible IDE

## How to Compile

```bash
javac BinaryTreeSearch.java
```

## How to Run

```bash
java BinaryTreeSearch
```

## Input Format
First enter the tree in preorder. Use `-1` for a missing node. Then enter the key to search.

Example:

```text
1 2 4 -1 -1 5 -1 -1 3 -1 -1
5
```

## Complexity
- Each traversal: `O(n)`
- Search in a general binary tree: `O(n)`
- Tree construction: `O(n)`
- Auxiliary recursion stack: `O(h)`
